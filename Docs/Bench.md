# 📖 대기석 (Bench) 시스템 상세 기획서

## 1. 시스템 개요

- **정의:** 플레이어가 획득한 예비 볼(캐릭터)을 보관하고, 3-Merge(합성)를 대기시키며, 전투에 나설 출전 슬롯(최대 3개)의 멤버를 교체/세팅하기 위한 인벤토리 공간.
    
- **최대 수용 용량:** 총 **9칸** (TFT 룰 차용).
    

## 2. UI/UX 및 시각 연출

- **호출 방식:** 화면 우측 상단의 '덱(가방) 아이콘' 클릭 시.
    
- **오픈 연출 (2D + 3D 결합):** * UI 패널 자체는 화면 우측에서 부드럽게 밀려오는 **2D 슬라이드 방식**을 사용하여 빠르고 가벼운 조작감을 제공.
    
    - 슬롯 내부에 들어있는 볼들은 **Render Target (Render Texture)** 기술을 활용해, 2D UI 위에서도 3D 오브젝트 고유의 입체감과 대기 애니메이션이 표현되도록 랜더링.
        
- **정보 확인 (툴팁):** 대기석의 볼에 마우스 오버(Hover) 시 해당 볼의 스탯, 스킬, 에너지, 시너지 정보를 담은 툴팁 UI 팝업.

## 3. 기본 조작 및 룰 (Drag & Drop)

- **스왑(교체) 및 장착:** 대기석의 볼을 드래그하여 중앙의 출전 슬롯(1~3번)에 드롭하면 즉시 장착되며, 원래 자리에 있던 볼은 대기석으로 스왑됨.
    
- **판매(버리기) 기능:**
    
    - 볼을 드래그하기 시작하면 화면 하단에 붉은색의 **판매 구역** UI가 활성화됨.
        
    - 볼을 해당 구역에 드롭 시 정해진 가치에 따라 재화 환급 후 소멸.
        
- **자동 합성 (3-Merge):** 상점 및 보상 페이즈에서 새로운 볼을 획득/구매하여 대기석과 출전석을 통틀어 동일한 1성 볼 3개가 모이는 즉시, 2성으로 자동 융합(합성)되는 연출 발생.
    

## 4. 예외 상황 및 안전 장치 (Edge Cases)

- **공간 부족 획득 불가 처리:**
    
    - 대기석(9칸)과 출전 슬롯(3칸)이 모두 가득 찬 상태에서 상점/보상 볼 획득 시도 시.
        
    - **피드백:** 획득하려던 볼이 좌우로 떨리며(거부 연출), 붉은색 아웃라인 깜빡임 및 에러 사운드(부저음) 출력. 화면 중앙에 _"대기석 공간이 부족합니다"_ 토스트 팝업 노출. 재화는 소모되지 않음.
        
- **실수 방지] 2성 이상 판매 팝업:**
    
    - 2성 등급 이상의 공을 판매 구역에 드롭할 경우, *"정말 판매하시겠습니까?"*라는 확인 팝업창을 출력하여 조작 실수 방지. (1성 공은 즉시 판매)
        
- **소프트락] 방지 최소 1개 보유 강제:**
    
    - 플레이어의 인벤토리(출전석+대기석 포함)에 공이 단 1개만 남아있을 경우, 해당 공은 드래그하여 판매할 수 없도록 강제 락(Lock) 처리. (전투 진행 불가 상태 방지)
        

## 5. 인게임(전투 중) 작동 정책 (1안 vs 2안)

본 게임의 코어 룰(투척 횟수 기반 전투)에 맞추어, 내부 테스트 및 밸런싱을 위해 두 가지 작동 정책안을 병행 기획함.

### 🔴 전투 중 교체 불가 (Pre-battle Strategy)

- **세팅/상점 페이즈:** 대기석의 모든 기능(교체, 판매, 합성) 100% 활성화.
    
- **전투 중(공격 대기 상태):** 대기석 UI를 열 수는 있으나 **조회 전용(View-Only)** 상태로 고정.
    
    - 볼을 드래그/스왑/판매할 수 없으며, 마우스 오버 툴팁으로 보유 현황만 확인 가능. (전투 진입 전 세팅의 중요성 강조)
        

### 🔵 전투 중 교체 가능 & 페널티 (Mid-battle Tactics)

- **세팅/상점 페이즈:** 모든 기능 100% 활성화 (1안과 동일).
    
- **전투 중(공격 대기 상태):** 대기석 ↔ 출전 슬롯 간의 **드래그 스왑(교체) 기능 허용.** (단, 판매 기능은 비활성화)
    
    - **교체 페널티 (에너지 초기화):** 출전 슬롯에서 에너지가 채워진 공을 대기석으로 내릴 경우, 보유하고 있던 스킬 게이지(에너지)가 **즉시 0으로 초기화**됨.
        
    - **합성 제한:** 전투 중 스왑을 통해 동일한 1성 공 3개가 모이더라도 **합성되지 않음.** (전투 종료 후 세팅 페이즈 돌입 시 즉시 자동 합성 처리)

## 6. 🔗 타 시스템 연동 명세

세부 로직은 각 시스템 기획서 참조

- **상점 및 보상 시스템:** 획득한 볼 데이터가 대기석의 빈 슬롯으로 유입.
- **경제 시스템:** 대기석의 기물 판매 시 획득하는 재화 산정 및 반환.
- **합성(3-Merge) 시스템:** 대기석(또는 출전석) 내에 동일한 1성 볼 3개가 감지될 경우, 2성으로 자동 진화하는 로직 호출.
- **출전 슬롯 시스템:** 대기석 ↔ 출전석 간의 데이터 이동 및 스왑 처리.
